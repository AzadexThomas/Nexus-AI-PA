# Private dossier and creditor assistance

The private interface now resolves supply helpers in the same scope as its main router. Browser tests cover Dashboard, conversation, Tasks and Supplies; syntax checks alone did not catch the original reference error.

Authenticated owner requests can retrieve selected sections from a fixed private reference document through the existing signed connector. Responses retain source version/date, distinguish dated reports from current provider records, and grant no execution permission. The full document is not copied into agent knowledge bases, GitHub or ordinary operational logs. Family sessions, unverified callers and ordinary outbound contact calls cannot use this path.

Owner corrections preserve provenance, historical evidence and concurrent revision checks. The database supplies current correction overlays immediately. Background synchronization uses exact existing file identities, optimistic file-version checks, idempotent correction markers and readback of both Markdown and PDF. A failed or partial synchronization stays unconfirmed with a durable retry delay. A hosted preview validated source access without modifying either source file. A subsequent authorized directory-metadata update passed exact readback for both existing files; the updated PDF was rendered for inspection. Identity-secret values were not copied or claimed verified.

Creditor assistance uses a separate voice agent and account-specific structured authorizations. It does not relax the family/contact-call scope. Durable cases distinguish requests, scheduling, dial attempts, representative connection, offers, owner review, uncertain outcomes and confirmed enrollment. A saved blocked request is not a scheduled call. Dispatch checks account identity, servicing destination, institution authorization, source freshness, pause/cost controls and the requested date. Reservations precede provider submission; unknown commitments are never blindly repeated.

The generic offer contract rejects incomplete terms, fees, positive required payments, continuing interest, account closure, adverse reporting, shorter/different durations and prohibited financial commitments. Auto-loan and mortgage modifications always require owner review. An eligible policy result alone cannot execute anything: acceptance also requires a correlated verified call, current account authority and separately verified written terms. Confirmed enrollment requires a matching verified written confirmation, not merely a verbal report or a queue receipt.

Identity secrets remain outside the dossier and ordinary logs. Where a creditor requires owner authentication and no purpose-specific secure disclosure flow is verified, the task is blocked for owner participation. No authentication bypass or account-holder impersonation is supported. The dedicated agent disables audio recording, limits transcript retention and has bounded call duration, concurrency and daily calls.

Validation includes synthetic backend policy/state/access tests, rendered browser views, two hosted all-tools-mocked authentication/unsafe-offer simulations, and bounded production source checks. An earlier combined simulation became inconclusive because safe early termination prevented its later offer criterion from being reached; focused scenarios separately passed. No real creditor call or enrollment was used for testing. Live institution authentication, written-offer ingestion and an actual enrollment outcome remain unverified; the initial real cases remain blocked.
